## Focus

Introduction to AI-based coding agents in software development and the collaboration between developer and agent.

## What We Worked On

- worked with coding agents as a development tool
- used an agent on a concrete programming task
- documented the process and the result in the portfolio

## Key Concepts

The material focused on coding agents as support for architecture, debugging, refactoring, and testing. The point was not to replace the developer, but to shift the developer's role toward steering, scoping, and quality control.

The published material for this lesson was brief, so the most important point was the workflow itself: solve a real task with a coding agent and document the collaboration, not only the end product.

## Key Takeaways

- coding agents are most useful when the task is clearly scoped
- documenting decisions and iterations is part of the work
- the quality of the collaboration depends on clear prompts and technical judgment
