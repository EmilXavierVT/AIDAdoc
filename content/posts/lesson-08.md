## Focus

Project kickoff with team formation, a project description, and a system sketch for an AI-driven application.

## What We Worked On

- formed project teams
- started the development process
- worked on the project description and system sketch

## Key Concepts

The material for this lesson was brief, but the deliverable was clear: the project had to be described and scoped early so development would not begin without an overview of the idea, user needs, and system context.

The system sketch therefore became an important link between the idea and the implementation.

## Key Takeaways

- team formation and scope need to be established early
- a system sketch creates shared direction before the codebase grows
- AI projects require just as much clarification of problem and flow as of model choice
